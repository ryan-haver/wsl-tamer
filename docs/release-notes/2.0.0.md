WSL Tamer 2.0 is a ground-up rebuild focused on safety and reliability.

**Upgrading from 1.x:** download and run WslTamer-win-Setup.exe from this release. Your profiles and rules carry over automatically, and on first launch 2.0 offers to remove 1.x.

Highlights:

- No longer runs as administrator. It asks for permission only to share a USB device, attach a disk or compact a disk. "Start with Windows" now works.
- Profiles change only the settings they list. The rest of your .wslconfig (including comments and settings WSL Tamer doesn't know about) is kept, with a backup saved on every change.
- The wsl.conf editor keeps settings it doesn't recognise and never saves over a file it couldn't read.
- Disk compaction was rewritten to use diskpart (1.x called a wsl.exe option that doesn't exist). You can also switch a distribution to a sparse disk that shrinks automatically.
- Moving a distribution uses WSL's built-in move instead of export, delete and re-import. Cloning keeps your default user, and a running distribution can be cloned without stopping it.
- When WSL is still holding a distribution's disk, WSL Tamer offers to shut WSL down and retry instead of failing.
- The "restart WSL to apply" reminder notices .wslconfig changes made in any editor and survives restarting the app.
- Automation adds time windows and power source, and uses network names that work without location permission.
- New: keep distributions running in the background, restart WSL automatically when idle to apply changes, and edit every documented .wslconfig setting.
- Updates are delivered with Velopack and verified by checksum before installing.

Removed: the "folder mount" feature and the PCIe placeholder page.

Known limitations in this release:

- The installer is not code-signed yet, so Windows SmartScreen may warn when you run it. Choose "More info" and then "Run anyway".
- A few features are implemented but haven't been tested on real hardware yet: the distribution "…" menu actions and the tray menu (the operations behind them are tested), disk compaction, USB passthrough and physical disk attach. See docs/TESTING.md in the repository. Please report anything that misbehaves.
